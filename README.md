# AI_Interviewer

이력서와 직전 답변을 반영해 후속 질문을 생성하고 면접 기록을 종합해 피드백을 출력하는 AI 면접관 프로토타입입니다.

| 항목 | 내용 |
| --- | --- |
| 기간 | 2025.10 - 2025.11 |
| 팀 구성 | 6인 팀 |
| 개인 참여 | RAG 검색과 질문 생성 작업을 중심으로 공동 개발 |
| 핵심 기술 | Python, LangChain, LangGraph, FAISS, OpenAI Embeddings, Gradio |

팀원들과 기능을 나누어 함께 개발했습니다. 이 저장소에는 팀 결과보고서와 Gradio 구현본을 바탕으로 정리한 설명 문서를 공개했습니다.

## 문제 정의

이력서만으로 질문을 만들면 최초 질문에는 지원자 정보를 반영할 수 있지만 이후 질문에는 직전 답변의 맥락을 반영하기 어려웠습니다. 벡터 검색 결과도 현재 질문의 목적에 맞는지 추가로 고려해야 했습니다.

이력서 키워드와 이전 질문, 답변을 검색 조건으로 사용하고 질문 카테고리와 키워드 일치도를 반영하는 방식을 적용했습니다.

## RAG 검색과 질문 생성

```text
면접 질문 CSV의 category, content
  → OpenAI 임베딩
  → FAISS 검색

이력서 키워드 + 이전 질문과 답변
  → 유사 질문 후보 검색
  → 카테고리와 키워드를 반영한 재정렬
  → 검색 결과를 Context로 전달
  → 답변 맥락을 반영한 후속 질문 생성
```

검색한 질문을 그대로 제시하지 않고 검색 결과를 참고해 지원자의 답변에서 더 확인할 내용을 질문하도록 구성했습니다.

## 팀 시스템의 상태 관리

`InterviewState`에 이력서 요약과 키워드, 현재 질문과 답변, 대화 기록, 평가 결과를 관리했습니다. 답변 평가, 다음 행동 판단, 질문 생성 또는 종료, 최종 피드백의 흐름을 LangGraph로 연결했습니다.

Gradio 구현본에서 확인한 모델 구성은 다음과 같습니다.

| 기능 | 모델 또는 도구 |
| --- | --- |
| 이력서 분석, 질문 전략, 답변 평가와 질문 생성 | GPT-4.1-mini |
| 최종 피드백 보고서 생성 | GPT-4o-mini |
| 질문 데이터 임베딩 | text-embedding-3-large |
| 유사 질문 검색 | FAISS |

팀 발표자료에는 Whisper STT와 OpenAI TTS를 연결한 음성 인터페이스도 포함되어 있습니다. 개인 참여 범위는 RAG 검색과 질문 생성 중심의 공동 작업으로 구분합니다.

## 답변 평가와 구현 범위

팀 시스템에서는 질문과의 연관성, 답변의 구체성을 상, 중, 하로 평가했습니다. 자기소개 질문에는 자기소개 완성도와 진정성, 이력서 일관성 등을 추가했습니다.

평가 결과는 State에 저장하고 다음 행동을 판단하거나 최종 피드백을 생성할 때 참조했습니다.

## 팀 결과

고정된 질문을 순서대로 제시하는 방식에서 지원자의 이력서와 직전 답변을 반영해 후속 질문을 생성하는 구조로 바꿨습니다. 면접 종료 후에는 대화와 평가 기록을 종합한 피드백을 출력했습니다.

현재 이 공개 저장소에는 소스 코드와 실행 환경이 포함되어 있지 않습니다.
